# 🚀 Desmond’s Gradio App

This is a simple Gradio application deployed on **Hugging Face Spaces**.

## 📌 About
- Built with **Python** and **Gradio**
- Deployed automatically from **GitHub → Hugging Face** using GitHub Actions
- Entry file: `app.py`
- Dependencies: listed in `requirements.txt`

## 🔧 How it works
1. Push changes to the `main` branch on GitHub  
2. GitHub Actions syncs the repo to Hugging Face  
3. Hugging Face builds & runs the app automatically
